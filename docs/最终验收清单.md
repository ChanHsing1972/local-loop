# 最终验收清单

本清单用于功能冻结、录制和提交当天。自动检查通过不代表可以跳过人工视频与提交物检查。

## 仓库冻结前

- 运行 `ruff check .` 与 `pytest --cov=localloop --cov-report=term-missing --cov-fail-under=85`，要求全部通过且核心覆盖率不低于 85%。
- 运行 `python scripts/release_check.py`，检查完整 Git 历史、凭据特征、本机绝对路径、指定提交身份、运行时文件、必需文档和 README.txt 字数。
- 确认所有历史提交的 Author 与 Committer 都是 `Liu Yuxuan <231880433@smail.nju.edu.cn>`，且历史重写后的 main 已推送。
- 使用未登录浏览器打开仓库，并运行 `python scripts/release_check.py --online`，确认仓库可以匿名访问。
- 作废任何曾出现在对话、终端历史、截图或提交中的旧密钥；真实密钥只能保存在本机环境变量或未入库 `.env`。
- 从全新检出创建虚拟环境，执行 `python -m pip install .`，从 `.env.example` 创建未入库 `.env`，再执行 `localloop doctor` 和演示任务，确认安装说明可复现。
- 每次功能冻结后重新执行 `python -m pip install --force-reinstall .`；用 `localloop --version` 确认没有误跑 site-packages 中的旧版本。

## 视频录制

- 运行 `python scripts/prepare_demo.py`，只在脚本生成的临时项目中演示；初始 pytest 应恰好有两项失败。
- 隐藏菜单栏、无关通知、主目录敏感路径、API 值和 `.env`；个人身份可以正常出现，但凭据绝不能出现。
- 视频保留“查看项目→读取代码→流式分析→展示 diff→运行测试→根据结果继续→最终总结”的因果链，并简要展示 Agent 循环和安全边界。
- 导出 H.264 MP4；时长严格小于 120 秒，文件严格小于 200 MB；完整观看导出文件，核对画面、声音、字幕和凭据信息。

## 最终压缩包

- README.txt 不超过 1000 汉字，包含可匿名访问的真实仓库地址、安装运行方式、特色功能和限制。
- ZIP 内部只保留 `README.txt` 与一个 MP4 视频，不放源码、PDF、日志、`.env`、截图或其它文件。
- 外层 ZIP 按要求使用本人姓名命名；ZIP 内仍只保留 README.txt 和视频。
- 在截止时间前上传并重新下载最后版本，解压核对两个文件均可正常打开；保留本地备份和提交成功页面截图。
- 最终推送完成后不再改写历史；功能冻结时再创建 `v1.0.0` 标签，截止时间后停止任何 push。
