# 一分钟英文介绍

## 推荐正文（约 125 词）

> LocalLoop is an interactive coding agent that I built without an agent framework. The model can return text or request five local tools, but my program owns the control loop. It manages conversation history, reconstructs streamed tool calls, validates paths and arguments, executes tools locally, feeds matched results back to the model, and decides when to stop. For reliability, LocalLoop uses hash-protected atomic writes, explicit approval, shell-free commands, bounded retries, deterministic context compaction, and resumable JSONL sessions. Unit tests cover deterministic edge cases, while a real gateway check verifies native tool calling and result feedback. The main lesson is that a useful coding agent is not just a model; it is a system for control, evidence, recovery, and honest failure handling.

## 中文理解

LocalLoop 不依赖 Agent 框架。模型只能输出正文或请求五个本地工具，控制循环由程序掌握：管理历史、重组流式工具调用、验证参数、本地执行、按调用编号回填结果、决定终止。可靠性来自哈希保护的原子写入、明确审批、无 Shell 命令、有限重试、确定性上下文压缩和可恢复 JSONL。最后一句表达项目核心观点：Agent 的价值不仅来自模型，还来自控制、证据、恢复和诚实的失败处理。

## 断句与发音

建议在以下位置短暂停顿：“LocalLoop is an interactive coding agent / that I built without an agent framework. / The model can return text / or request five local tools / but my program owns the control loop.” 正常语速约 50-58 秒。

- `interactive`：in-ter-ACT-ive
- `reconstructs`：ree-con-STRUCTS
- `deterministic`：de-ter-mi-NIS-tic
- `compaction`：com-PAC-tion
- `resumable`：re-ZOO-ma-ble
- `reliability`：re-lia-BIL-i-ty

## 两个常见追问

**Why did you avoid an agent framework?** “The assignment requires the key logic to be implemented independently. Writing the loop myself also makes every state transition testable and explainable.”

**What is the main limitation?** “The safety layer prevents common mistakes, but it is not an operating-system sandbox, so automatic approval is only suitable for trusted, disposable workspaces.”
