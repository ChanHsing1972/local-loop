# 一分钟英文介绍

## 推荐正文（约 125 词）

> LocalLoop is an interactive coding agent that I built without an agent framework. An OpenAI-compatible model can request five local tools to inspect files, search code, write changes, and run tests. My program owns the entire control loop: it streams model output, reconstructs fragmented tool calls, validates every action, returns matched tool results, manages context, and decides when to stop. For reliability, it uses hash-protected atomic writes, explicit command approval, bounded retries, deterministic context compaction, and resumable JSONL sessions. Unit tests use a fake provider for deterministic edge cases, while a real API test verifies native tool calling and result feedback. This project taught me that a useful agent is not just a model; it is a carefully designed system for control, evidence, recovery, and honest failure handling.

## 中文理解

LocalLoop 是一个没有使用 Agent 框架的交互式编程智能体。模型可以请求五个本地工具来查看文件、搜索代码、写入修改和运行测试，但完整控制循环由程序掌握：流式显示、拼接分片工具调用、验证操作、回填匹配结果、管理上下文和决定终止。可靠性来自哈希保护的原子写入、命令审批、有界重试、确定性上下文压缩和可恢复 JSONL 会话。FakeProvider 负责确定性边界测试，真实 API 负责验证原生工具协议。最后一句是项目观点：Agent 不只是模型，而是控制、证据、恢复和诚实失败处理组成的系统。

## 可能的英文追问

“Why did you avoid an agent framework?” 可以回答：“The assignment requires the key logic to be implemented independently. More importantly, writing the loop myself makes every state transition testable and explainable.” “What is the main limitation?” 可以回答：“The safety layer prevents common mistakes, but it is not an operating-system sandbox, so automatic approval is only suitable for trusted disposable workspaces.”
