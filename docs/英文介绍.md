# 一分钟英文介绍

根据考核要求，项目文档的解释部分使用中文；下方演讲正文必须在面试时使用英文，因此作为唯一的内容语言例外保留。全文 120 词，正常语速约 50 秒，介绍时不要说出姓名或本科院校。

> LocalLoop is a coding agent I built without an agent framework. A user gives it a programming task, and an OpenAI-compatible model selects five local tools to inspect files, search code, write changes, and run commands. The agent validates each tool call, returns the local result to the model, and repeats until completion or a safety limit. Its reliability features include workspace isolation, hash-protected updates, command approval, secret-free subprocess environments, bounded retries, deterministic context compaction, and resumable JSONL sessions. A fake model provider makes core tests deterministic and free of API cost. Building LocalLoop taught me that useful agents depend not only on model capability, but also on explicit control flow, careful permission boundaries, recoverable state, and honest failure handling.

中文含义：LocalLoop 是一个未使用 Agent 框架的编程智能体。模型通过五个本地工具检查文件、搜索代码、写入修改和运行命令，程序验证每次调用并把真实结果返回给模型。可靠性设计包括工作区隔离、哈希写入保护、命令审批、子进程密钥净化、有界重试、确定性上下文压缩和可恢复会话。FakeProvider 让核心测试不消耗 API。项目最重要的认识是：实用智能体不仅依赖模型能力，也依赖明确的控制流、权限边界、可恢复状态和诚实的失败处理。
