# 两分钟演示视频脚本

## 录制前

- 使用中性终端提示符和 `/tmp` 路径，隐藏菜单栏、账号头像、通知、Git 远程仓库所有者和所有 API 值。
- 把 `demo/price_project` 复制到 `/tmp/localloop-price-demo`，确认初始状态恰好有两项测试失败。
- 录制前单独运行 `localloop doctor`，通过后清屏，避免在视频中显示模型账号信息。
- 至少完整演练三次，并保留一份时长更短的备用录制。

## 推荐时间线

**0-12 秒：** 展示中文 README 架构图并说明：“LocalLoop 是一个不依赖 Agent 框架的交互式编程智能体，对话历史、工具执行、上下文管理和终止逻辑均由本地代码实现。”

**12-25 秒：** 在演示目录运行 `pytest -q`，展示两项初始失败；随后运行 `localloop --auto-approve`，让启动面板显示模型、目录和审批模式。

**25-80 秒：** 输入固定任务：“保持公共 API 不变。找出并修复金额精度问题和折扣阈值的边界 Bug，补充边界测试，并运行全部测试。”保留目录读取、文件读取、diff、测试命令和最终九项测试通过的因果过程；只加速等待时间，不剪掉关键步骤。

**80-95 秒：** 在同一交互会话继续输入：“请简要解释修复依据和当前安全边界。”用模型能引用上一轮结果证明多轮上下文有效。

**95-108 秒：** 快速展示 `agent.py` 的有界循环、`interactive.py` 的持续会话，以及 `tools.py` 的工作区限制、SHA-256 写入保护、无 Shell 命令和密钥环境净化。

**108-115 秒：** 总结：“测试使用 FakeProvider，无需 API 即可验证多轮调用、异常恢复、会话继续和安全边界；这些控制用于减少误操作，但不是操作系统沙箱。”

## 导出检查

导出 H.264 MP4，分辨率可使用 1080p 或 720p；确认时长小于 120 秒、文件小于 200 MB，并完整观看最终导出版本一次，检查声音、字幕和身份信息。
