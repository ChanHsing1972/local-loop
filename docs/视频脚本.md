# 两分钟演示视频脚本

## 演示目标

两分钟内只证明四件事：它能自主完成真实编程任务；回答确实流式显示；每个本地操作有具体输入和结果；核心循环、可靠性和安全边界由本项目实现。不要把时间耗在安装、模型列表或长篇 README 滚动上。

## 录制前准备

1. 整理终端画面，隐藏菜单栏、无关通知、主目录敏感路径和任何 API 值；不要打开或展示 `.env`。
2. 在画面外执行 `python -m pip install '.[dev]'` 和 `localloop doctor`，确认模型列表、原生调用和 Tool 回填通过。
3. 执行 `python scripts/prepare_demo.py`，进入输出的 `/tmp/localloop-price-demo-...`，运行 `pytest -q`，确认初始恰好两项失败。
4. 设置终端字号足够大，窗口约 100 列；清屏后开始录制。保留一份已经跑通的备用录像，真实模型偶发抖动时不要临场赌运气。

## 固定任务文本

“保持公共 API 不变。找出并修复金额精度问题和折扣阈值的边界 Bug，补充边界测试，并运行全部测试。”

## 精确时间线与旁白

### 0-10 秒：问题与项目

画面先显示失败的 `pytest -q`。旁白：“这是一个有两个失败测试的价格计算项目。接下来我让 LocalLoop 自主定位、修改并验证。它不使用 Agent 框架，控制循环和本地工具都由项目自己实现。”

### 10-22 秒：启动与输入

运行 `localloop --auto-approve`，输入 `/`，用两秒展示带说明、可选择的命令菜单，然后清空输入并粘贴固定任务。旁白：“斜杠菜单会列出所有本地命令；演示目录是一次性临时副本，所以开启自动批准，正常模式下写文件和命令会逐次确认。”

### 22-72 秒：保留完整因果链

画面保留以下事件并加速模型等待区间：列出 3 个文件；读取 README、`pricing.py` 和测试；流式出现对问题的分析；展示 `pricing.py` 的 diff；展示新增边界测试的 diff；运行 `pytest -q test_pricing.py`；显示退出码 0 和 `9 passed`。旁白：“终端不是只显示第几步，而是展示读取的文件和行号、写入字节、完整待执行命令、退出码与测试摘要。正文从 SSE 分片直接显示，工具调用参数在本地重组后才执行。”

### 72-90 秒：展示连续会话

在同一会话输入：“用两句话解释修复依据，并说明一个当前安全边界。”旁白：“第二次输入会追加到同一消息历史，模型能引用刚才的修复；`/new` 才会开始新上下文，`/resume` 可以从 JSONL 恢复。”

### 90-110 秒：快速展示核心代码

切到编辑器，依次停留：`agent.py` 的有界循环与终止分支；`provider.py` 的流式分片/工具参数重组和重试；`tools.py` 的 SHA-256 检查、`shell=False`、环境净化；`context.py` 的完整工具组压缩。旁白：“模型只提出动作。Agent 维护状态机，Provider 解析流，Tools 在本地验证执行，Context 保证压缩后仍满足工具消息协议。”

### 110-118 秒：证据与边界

显示测试结果截图或终端最后两行。旁白：“自动化测试覆盖流式分片、空响应、断流不重复、异常恢复和安全边界；真实 API 也通过原生工具闭环。防护用于减少误操作，但不是操作系统沙箱。”

### 118-120 秒：结束字幕

字幕：“LocalLoop — control, evidence, recovery.” 不再说新信息，留半秒结束缓冲。

## 剪辑原则

可以 2-4 倍加速纯等待，但不要剪掉“读代码 → 得出依据 → 展示 diff → 跑测试 → 根据退出码总结”的因果关系。若模型产生冗长正文，可裁掉中段，但至少保留连续出现的几个字来证明流式输出。不要展示 `doctor` 的完整模型列表，避免占时；不要展示 `.env`，即使 Key 已打码也没有必要。

## 故障备用方案

如果录制时空响应，停止本次录制，在画面外运行 `localloop doctor`；若失败则切换已验证模型或稍后重录，不要现场反复等待。如果工具调用已完成但最终回答断流，可使用 `/resume 会话编号` 展示恢复能力，但主成片仍优先采用完整成功的一次。真实故障可在答辩中解释为“HTTP 成功但语义空响应”，不能笼统说成网络不稳定。

## 导出核对

导出 H.264 MP4，720p 或 1080p，严格小于 120 秒和 200 MB。完整观看最终文件，确认声音清楚、字号可读且没有凭据。录制前后运行 `python scripts/release_check.py`；最终 ZIP 只放 `README.txt` 和 MP4。
